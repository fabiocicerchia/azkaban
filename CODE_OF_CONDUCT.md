# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment. Unacceptable
behavior can be reported privately to the maintainers via
[GitHub Security Advisories](https://github.com/fabiocicerchia/azkaban/security/advisories/new)
or by direct message. Maintainers will review and act on reports
confidentially.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
